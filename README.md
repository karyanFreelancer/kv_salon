# ✨ KV Salon – Full-Stack Salon Management Software

A modern and responsive Salon Management & Appointment Booking System built to simplify salon operations and provide customers with a smooth online booking experience.

The application includes customer registration, appointment booking, appointment tracking, service management and a secure admin dashboard.

## 🌐 Live Website

**Live Demo:** https://kvsalon.xo.je/kv_salon/kv_web/?i=1

## 📸 About the Project

KV Salon is a complete salon management web application designed for modern beauty salons and grooming businesses.

Customers can create accounts, explore salon services, book appointments online and track their booking status. Administrators can manage appointments, services, customers and customer messages through a dedicated dashboard.

## ⚙️ Installation & Setup (XAMPP)

Follow these steps to run the project locally.

**Step 1 – Download the Project**

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Or download the project as a ZIP file.

**Step 2 – Move to XAMPP**

Place the extracted project folder inside:

```text
C:\xampp\htdocs\
```

**Step 3 – Start XAMPP**

Start these services:
- Apache
- MySQL

**Step 4 – Create Database**

1. Open phpMyAdmin.
2. Create or select the required database.
3. Import the `database.sql` file.

**Step 5 – Configure Database**

Open `config.php` and update your MySQL credentials.

**Step 6 – Open the Website**

```text
http://localhost/velora_salon_software/
```
