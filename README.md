# Velora Salon — Full Software Application

## Modules
Customer:
- Register / Login / Logout
- Customer dashboard
- Profile update
- Book appointment
- View appointment history/status

Admin:
- Secure session login
- Dashboard metrics
- Appointment management/status
- Services management
- Customer CRM list
- Messages inbox structure

## Stack
PHP 8+, MySQL, HTML5, CSS3, JavaScript, Bootstrap 5, GSAP, ScrollTrigger, Lenis.

## XAMPP
1. Put this folder in `htdocs`.
2. Start Apache + MySQL.
3. Import `database.sql` in phpMyAdmin.
4. Check `config.php` for your MySQL credentials.
5. Open `http://localhost/velora_salon_software/`
6. Admin login: `admin@velora.local`
7. Admin password: `admin123`

Change the demo password before production use.
